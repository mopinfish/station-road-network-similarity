# Saved input supplement and transformation methods

This supplement supplies adopted classification decisions and reference inputs for the accompanying numerical database. It does not change any analysis result. The executable numerical workflow starts from saved road indicators. Road-network extraction code and the original OSM history are not distributed here; this document describes those upstream transformations and is not an executable end-to-end reproduction claim.

## OSM graph, origin, and extraction extent

The adopted upstream environment records Python 3.12.3, OSMnx 2.0.1, NetworkX 3.4.2, Shapely 2.0.6, pyproj 3.7.0, NumPy 2.2.1 and Python osmium 4.3.1. Python osmium and the osmium-tool 1.16.0 command-line snapshot tool are distinct packages.

Use EPSG:32654 for planar calculations. Accept ways with a highway key except values matching the substring regex `abandoned|construction|no|planned|platform|proposed|raceway|razed`; exclude area values containing `yes`. Do not add service/access filters from other network types. Build segments between consecutive referenced OSM nodes, skip repeated identical node references, but retain distinct nodes with zero-length separation. Compute lengths from projected geometry. Create both directions for the undirected study, simplify with OSMnx (`remove_rings=False`, `track_merged=True`), and convert to an undirected multigraph. Reciprocal duplicate edges are removed, while distinct parallel segments and loops remain. Preserve original way/node lineage and full segment geometry.

Start with a square context of half-width 1500 m around the station representative. Retrieve whole intersecting ways and all their referenced nodes, using densified transformed bounds (21 points; geographic padding 1e-5 degrees). If necessary, find the nearest segment against the saved index and increase context half-width to `max(1500, r+1000+500)`, where r is representative-to-origin offset. Use the same pre-extraction graph for 600, 800 and 1000 m. This is a finite computational context, not an assertion of equivalence with an infinite network.

The origin is the nearest point on a simplified segment, including zero-length segments as points. Use 1e-6 m for near-equal nearest candidates and endpoint matching. Multiple representations of one existing node are merged; genuinely distinct tied candidates remain unresolved instead of being arbitrarily chosen. Split a segment at an interior origin. The representative-to-origin offset does not consume the network-distance budget.

Run weighted shortest paths on the undirected segment lengths. Retain continuous reachable subintervals from both endpoints, merging overlapping intervals without bridging unreachable gaps. Add artificial boundary nodes. Zero-length segments require both ends reachable. Mark whether each original parent segment survives completely. The measurement graph contains reachable parts; its auxiliary graph removes artificial boundary leaves and suppresses an artificial degree-two origin, retaining original real nodes. A degree-one or isolated artificial origin is removed. Distances used for non-proximity exclusions are **Euclidean distances between the fixed road origins**, not station-centroid distances.

## Indicators and numerical transformations

Let L be total reached segment length, A the convex-hull area formed from measurement-node coordinates and all reached edge-geometry coordinates, and N/E/P the auxiliary graph's node/edge/component counts. Use A in hectares or square kilometres as required. Missing or undefined values are preserved instead of filled. Cycle rank is E−N+P, with mean circuit index defined as cycle rank per hectare; the measurement/auxiliary equivalence is checked. Alpha is `(E−N+P)/(2N−5)` and gamma `E/(3(N−2))` only for N≥3, beta E/N for N≥1. Degree statistics use the auxiliary multigraph. Weighted all-pairs shortest paths exclude identical nodes; mean path length is their arithmetic mean and average circuity is the mean network/Euclidean distance ratio for positive Euclidean separations.

Degree centrality and length-weighted closeness (`wf_improved=True`) are summarized by mean and sample standard deviation. Weighted betweenness uses `normalized=True`, `endpoints=False`; it is missing for N<3 or zero-length auxiliary edges. Street counts are computed on the pre-extraction graph at retained real nodes. Intersection counts use street count≥3, while the basic intersection count uses≥2. Complete-parent segments only determine mean street length, basic circuity (sum length / sum endpoint straight distance), and self-loop proportion. Clean intersection count uses real nodes with street count≥2, 15 m buffers and OSMnx `consolidate_intersections(rebuild_graph=False, dead_ends=False)`. Densities divide the specified counts or lengths by A; zero area and other zero denominators are missing. The nine algebraic duplicate definitions are: basic_n=N; basic_m=E; basic_k_avg=2 beta; basic_edge_length_total=L; basic_edge_length_avg=basic_street_length_avg; basic_street_length_total=L; basic_street_segment_count=E (the adopted auxiliary graph invariant); basic_edge_density_km=100 road_density_Dl_m_per_ha; basic_street_density_km=100 road_density_Dl_m_per_ha. Basic node, intersection and clean-intersection densities use N, the street-count≥2 count and clean count respectively, divided by square kilometres. These duplicates share their representative's definition domain and missingness. All 39 recorded indicators comprise these nine duplicates, the component-count audit quantity, and 29 candidates. The accompanying candidate registry identifies their order and categories.

Feature selection uses quality status ok, no quality hold, and complete finite values for the 29 candidates. In that selection population, clamp raw values at Q1−3 IQR and Q3+3 IQR (linear quartiles), then fit RobustScaler to the clamped values. Retain scaled sample variances strictly above 0.05. Repeatedly choose the largest variance (first in candidate order for ties), remove other remaining candidates whose absolute Pearson correlation with it exceeds 0.7, and continue. Restore the selected set to candidate order for the numerical vector. This produces the fixed eight features. Selection scaling on clamped candidates and the final main scaling on the selected raw features are distinct stages; no new selection is performed in this supplement.

The eight adopted components are road density (m/ha), average circuity, mean degree centrality, mean closeness centrality, mean pre-extraction street count, complete-segment basic circuity, complete-segment self-loop proportion, and clean-intersection density (/km²). Saved indicators and scales are used without new feature selection. The main scaling is `(x−median)/IQR`, using linear-interpolated quartiles and the adopted fit population. The Clip comparison clamps each raw value to `[Q1−3 IQR, Q3+3 IQR]` and uses the **same main center/scale**, without refitting. Clip is a numerical tail treatment, not spatial clipping of roads. Cosine similarity is the normalized vector dot product; undefined zero vectors are excluded according to the stored eligible IDs. Candidate ranking is descending similarity with station ID as deterministic secondary order and excludes self. Range-specific scales, alternative scaling, fixed component exclusions and park conditions remain distinct comparisons. For 600 m and 1000 m, fit the same median/IQR formula separately to each range's own quality-eligible, eight-feature-complete population; 800 m uses the adopted main fit. The alternative mean/standard-deviation scaling is fitted once to the main fit population with population standard deviation (`ddof=0`); one-feature exclusions retain the corresponding fitted columns. Removing nearby candidates does not refit scales; it reranks and replenishes from the shared eligible candidates. The public numerical code and stored settings specify exact arithmetic and comparison populations.

## Park removal and the adopted additional decisions

Assemble leisure=park/garden areas from the same snapshot. Keep area-assembly failures explicit; do not silently repair them. Positive-length portions of footway/path/pedestrian/steps inside these areas are candidates; boundary-only and zero-length portions are not removed. Footway sidewalk/crossing remains. Identify structures when `bridge` (default `no`) is not the string `no`, `tunnel` (default `no`) is not `no`, or `layer` (default `0`) is not `0`. Ordinary non-structure candidates have their eligible interior portions removed in **both** conditions directly. The supplied **adopted** `way_id,final_class` table applies only to structure candidates and must not be replaced with an automatic classification proposal. Its 1545 entries are 697 park_path, 59 crossing_structure, and 789 undetermined.

For those structure candidates, basic removal deletes park_path; the additional condition also deletes undetermined. crossing_structure is retained. Use original-way lineage inside simplified parent segments. Keep surviving pieces and new cut endpoints, without re-simplification. Preserve the main origin's parent and position, with no re-snapping: a removed or isolated origin is undefined. Compute the 800 m reachable network after cuts. Length and convex hull use reachable pieces; complete-segment metrics require intact complete parents; street counts use the surviving pre-extraction pieces. Main scales stay fixed. Comparable station populations are 610 and 608.

`park_area_decisions.json` supplies the five adopted area decisions: exclude four out-of-study-region relations and one administrative relation; retain the two listed regular park areas. It does not authorize general omission of unresolved areas. All other area-incomplete handling remains unchanged. Private review observations and correspondence are not part of this supplement.

## Regional comparison

Use the union of the supplied TMU polygons and test whether it covers each station representative point, including the boundary. The adopted 614-station population includes 44 inside stations. The `inside` column in the numerical dataset is this classification; it is not a classification by the road origin. Do not reinterpret pairs of inside stations as exclusively pairs within one district. Non-proximity filtering removes pairs, not these stations or their memberships.
